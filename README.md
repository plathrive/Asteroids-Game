# Asteroids Game
This is my first game that i build inside a terminal, using unix environment. It's a game about shooting asteroids.
Take a lot of work for this to succeed for me, and so many attempts that i need to go through to completing this project.
This project took place in Boot.dev 6th course in Devops path. The project itself forces me to understand deeply about
Object Oriented Programming (OOP), and a lot of concepts in it directly applied to the Asteroids Game project.
### How to play it?
Simply clone or download this repo, install python (if you haven't), open your terminal (cmd, powershell, or unix), and run:
```
uv run main.py
```
Happy shooting asteroids!
